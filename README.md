## 🎸 Features

- Interactive virtual guitar
- Play strings with mouse or touch
- Keyboard controls for desktop
- Mobile-friendly touch interaction
- Swipe up/down to strum the guitar
- Chord selection
- Basic chord playback
- Volume control
- Responsive design for desktop and mobile

## 🚧 Status

The project is currently under development.

The main goal is to create a simple and interactive virtual guitar experience for both desktop and mobile devices.
